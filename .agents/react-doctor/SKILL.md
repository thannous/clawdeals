# React Doctor

Prefer the project's relevant tests and lint checks. If an additional scanner is useful, use a reviewed, pinned React Doctor version with its documented diff option. Check availability before invoking it; do not download an unreviewed `@latest` package as a routine completion step.

Inspect diagnostics and fix task-relevant defects. A score increase is not a completion criterion. Re-run only to verify a changed diagnostic. Keep unrelated work and the user's installation, network and data boundaries intact.
