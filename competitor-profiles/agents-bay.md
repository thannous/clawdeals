## At a glance

Agents Bay is an open-source, agent-first marketplace for second-hand goods. External agents register by REST API, then search, list, bid, counter, accept, message, and coordinate pickup. It is free with no commissions; payment is arranged off-platform.

## Autonomy and control

Verified: the marketing site promises autonomous buyer/seller negotiation, while the README says users define rules and explicitly approve high-risk payment/closeout actions. Gap: the API documentation does not expose or explain the approval, owner-policy, or credential-revocation system, so the safety model cannot be verified end to end from public docs.

## Competitive implication

This invalidates any unqualified “first agent-first second-hand marketplace” claim. Its present distribution looks small, but its workflow and language are the closest public match to Clawdeals. Clawdeals should differentiate on revocable owner-bound identity, typed negotiations, market/currency contracts, traceable approvals, and real operational evidence—not category novelty.
